# Electricity Tracking Home Card

This folder contains the Home screen electricity tracking card and its chart.

## Usage
- The card reads data from `electricityTrackingHomeNotifierProvider` and renders monthly analytics.
- It navigates to `ElectricityTrackingScreen` when tapped.

## Quick check
Run a widget test:

```bash
flutter test test/home/electricity_tracking_home_card_test.dart
```
